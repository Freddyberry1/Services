# Alfred Otu | AI & Digital Solutions Portfolio

Personal portfolio website for Alfred Otu, showcasing AI video generation, business automation, web and app development, social media management, brand building, and AI/digital training.

## GitHub Pages

This project is prepared as a plain static site for GitHub Pages. It requires no Node.js, PHP, Python, database, or external build step.

### Files

```text
index.html
404.html
.nojekyll
README.md
assets/
  alfred-otu.jpg
```

### Publish on GitHub

1. Create a new GitHub repository, for example `alfred-otu-portfolio`.
2. Upload the **contents of this folder**, not the ZIP file itself.
3. Keep `index.html` and `.nojekyll` in the repository root.
4. Keep `assets/alfred-otu.jpg` at exactly that path.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select **main** and **/(root)**, then click **Save**.
8. GitHub will publish the site at:

```text
https://YOUR-GITHUB-USERNAME.github.io/alfred-otu-portfolio/
```
